## Limits

These are controlled browser/component checks, not physical-device or real-wallet transaction proofs. Text-size testing doubles CSS text, not native browser pinch zoom. Asset images are controlled external I/O and bundled app fonts are not loaded in the isolated Playwright harness. The full shell's land-selection integration was source-revalidated; focused tests verify utility callbacks, while the global integration pass belongs to root. Warehouse's only production caller remains inside the main FarmViewProvider; both isolated test mounts provide the corresponding mocked navigation boundary, and `/qa/building-guards` does not mount Warehouse. No package/config changes, full build/browser matrix, production transaction, app-server control, commit or push was performed by this worker. The standalone gameplay smoke runners use their own temporary local fixture servers. The prior high/medium transaction controllers and metadata/readiness safeguards remain in place.
